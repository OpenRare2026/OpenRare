# 排序宽表字段说明

本文档说明基因组变异分析报告所使用的**排序宽表 CSV** 各字段含义、版本差异，以及报告生成时的解读逻辑。

适用文件示例：

| 版本 | 示例路径 | 列数 |
|------|----------|------|
| 旧版（testcase） | `test_data/test_case/testcase.csv` | 83 |
| OpenRare V3 | `test_data/test_case/v3_P001_case/06_result_sorting/vep_output.sorted.csv` | 101 |

更完整的 VEP/排序字段逐列说明见：`test_data/test_case/test_case.md`  
V3 原始表头说明见：`test_data/test_case/v3_P001_case/06_result_sorting/vep_output.sorted.header_fields.zh.md`

> 缺失值：`-` 表示无注释或不可用；`.` 多来自 VCF 原始缺失。

## 1. 命名规则

### 1.1 基础坐标

| 字段 | 含义 |
|------|------|
| `chrom` | 染色体（GRCh38） |
| `pos` | 1-based 变异位置 |
| `ref` | 参考等位基因 |
| `alt` | 替代等位基因 |

### 1.2 `vcf_info_*` 前缀

宽表中 **`vcf_info_` 开头**的列，由 pipeline 从 **VCF 的 INFO 字段**展开：

```text
VCF:  INFO/REG_CCRE_CLASS=PLS
CSV:  vcf_info_REG_CCRE_CLASS=PLS
```

规则：`vcf_info_<原始 INFO ID>`

## 3. Reads 与测序质量（重点）

### 3.1 什么是 reads？

WES/WGS 测序会把 DNA 切成短片段逐条测序，**每一条测到的序列称为一条 read（读段）**。

在某个位点上：

- 序列与参考基因组一致的 reads → **REF reads**
- 序列携带变异的 reads → **ALT reads**

**reads 数目 = 该位点测序「投票数」**：票越多，基因型（杂合/纯合/是否检出）越可信。

### 3.2 相关字段

| 字段 | 英文全称 | 含义 | 报告用途 |
|------|----------|------|----------|
| `vcf_info_REF_DP` | REF Depth | 支持**参考序列**的 reads 条数 | §3.3.1 Reads 支持 |
| `vcf_info_ALT_DP` | ALT Depth | 支持**变异序列**的 reads 条数 | §3.3.1；ALT&lt;3 建议 Sanger |
| `vcf_info_VAF` | Variant Allele Fraction | 变异 reads 比例，通常 `ALT_DP/(REF_DP+ALT_DP)` | §3.3.1 测序等位基因比例（**优先**） |
| `vcf_info_AF` | Allele Frequency | **GATK 基因型**等位基因频率 | 无 read 计数时的 fallback；与 VAF 差≥5% 时并列展示 |
| `vcf_info_DP` | Depth | 位点总测序深度 | §3.3.1；DP&lt;10 可信度下降 |
| `vcf_info_AC` | Allele Count | ALT 等位基因计数 | 质控/联合基因型 |
| `vcf_info_AN` | Allele Number | 参与计数的等位基因总数 | 配合 AC |
| `vcf_info_QD` | Quality by Depth | QUAL÷DP，位点质量 | §3.3.1；QD&lt;2 质量一般 |
| `vcf_info_FS` | Fisher Strand | 链偏倚（测序 artifact 信号） | §3.3.1 碱基质量指标 |
| `vcf_info_MQ` | Mapping Quality | 比对质量 RMS | §3.3.1 碱基质量指标 |
| `vcf_info_SOR` | Symmetric Odds Ratio | 链偏倚相关指标 | GATK 质控 |
| `vcf_info_BaseQRankSum` | Base Quality Rank Sum | REF/ALT reads 碱基质量差异检验 | GATK 质控 |
| `vcf_info_MQRankSum` | MQ Rank Sum | REF/ALT reads 比对质量差异检验 | GATK 质控 |
| `vcf_info_ReadPosRankSum` | Read Pos Rank Sum | REF/ALT reads 在 read 内位置差异 | GATK 质控 |
| `vcf_info_MLEAC` / `MLEAF` | Max Likelihood AC/AF | GATK 最大似然 AC/AF | 基因型估计 |
| `vcf_info_ExcessHet` | Excess Heterozygosity | 过量杂合度 | 质控过滤 |
| `vcf_info_InbreedingCoeff` | Inbreeding Coefficient | 近交系数 | 质控 |
| `vcf_info_END` | End position | 区间型变异结束坐标 | CNV/大 indel |
| `vcf_info_RAW_MQandDP` | Raw MQ and DP | GATK 中间统计 | 质控 |

### 3.3 AF 与 VAF 的区别

| | `vcf_info_AF` | `vcf_info_VAF` |
|---|---------------|----------------|
| 层级 | GATK **基因型**层面 | **测序 reads** 层面 |
| 计算 | 软件推断（AC/AN 等） | 实际数 REF/ALT reads |
| indel | 可能与 reads 严重不一致 | 更贴近真实 read 支持 |
| 报告 | 无 read 数据时使用；有冲突时并列 | **有则优先**作为「测序等位基因比例」 |

**典型问题案例**：

```text
REF_DP=8, ALT_DP=2  →  VAF=20%（仅 2 条 read 支持变异）
vcf_info_AF=0.5     →  GATK 显示 50%「杂合」
```

此时报告应写：**不能按 50% 杂合解读，建议 Sanger 验证**，而非「VAF 50% 杂合」。

### 3.4 reads 数目对解读的影响

| ALT reads | 常见解读 |
|-----------|----------|
| 0 | 通常未检出 ALT |
| 1～2 | 可能是真变异或测序/比对错误，**极不可靠** |
| ≥3～5 | 开始有一定信心（报告规则：ALT&lt;3 提示 Sanger） |
| ≥10～20 | 杂合/纯合判断较稳 |

| 总深度 DP | 影响 |
|-----------|------|
| &lt;10 | 等位基因比例整体可信度有限 |
| ≥30 | 通常较可靠（仍要看 ALT reads） |

**报告自动提示规则**（`report/models.py`）：

- `ALT_DP < 3` → 支持变异的 reads 偏少，建议 Sanger 验证
- `DP < 10` → 测序深度偏低，等位基因比例可信度有限
- `|VAF - AF| ≥ 5%` 且有 read VAF → reads 比例与 GATK AF 不一致，优先参考 reads
- `QD < 2` → 位点质量指标 QD 偏低

## 4. Phasing（相位）

### 4.1 概念

人类有两套染色体（父源、母源）。同一基因上若有**两个杂合变异**，需知道它们是否在同一条染色体上：

| 术语 | 含义 |
|------|------|
| **顺式（cis）** | 两个变异在**同一条**染色体上 |
| **反式（trans）** | 两个变异在**不同**染色体上 |

**Phasing（相位）** = 推断变异等位基因与附近其他变异是否位于同一条染色体。

对**常隐**疾病：反式更支持**复合杂合**；顺式可能只有一个有害等位基因。

### 4.2 相关字段

| 字段 | 含义 | 常见值 |
|------|------|--------|
| `vcf_info_BEAGLE_PHASED` | 是否经 **Beagle** 相位软件处理 | `0`=未相位 / `1`=已相位 |
| `vcf_info_PHASING_CONFIDENCE` | 相位置信度 | `HIGH` / `LOW` / `UNPHASED` |
| `vcf_info_CHN_REF_SUPPORT` | 中国参考面板是否支持该位点 | 本地参考覆盖情况 |
| `vcf_info_CHN_ALT_CARRIER_COUNT` | 中国参考库中携带 ALT 的**个体数** | 整数；`0` 表示面板中未见到携带 |
| `vcf_info_CHN_ALT_AC` | 中国参考库中 ALT **等位基因计数** | 整数 |

> **CHN_*** 列属于**中国人群参考频率**，不是相位本身，常与 gnomAD 对照使用。

### 4.3 报告展示与解读

**展示条件**（§3.3.1b）：`PHASING_CONFIDENCE=HIGH` 且 `BEAGLE_PHASED=1`

**合理解读**：

- 仅 **1 个变异**：即使 HIGH，也只说明该位点相位推断可靠，**不能写「已确认复合杂合」**
- **同基因 ≥2 个杂合变异** + HIGH：可讨论顺式/反式，**建议家系 trio 验证**
- **单人样本**：相位为统计推断，仅供参考

**不应写**：单人、单变异时写「两变异反式复合杂合已确认」。

## 5. 假基因（Pseudogene）

### 5.1 概念

**假基因**是进化过程中失去正常蛋白编码功能的 DNA 片段，像「基因的残片/复印件」，**通常不产生有功能蛋白**。

### 5.2 相关字段

| 字段 | 含义 |
|------|------|
| `vcf_info_is_pseudogene` | 坐标是否落在假基因相关区域：`Yes` / `No` |
| `vcf_info_pseudogene_name` | 命中的假基因 HGNC 名称（多个用 `;` 分隔） |
| `vcf_info_pseudogene_source` | 证据来源，如 `GENCODE.v49`、`Pseudogene.org` |

### 5.3 报告展示与解读

**展示条件**：仅 `is_pseudogene=Yes` 时进入 §3.3.1b（**不展示「否」**）

**合理解读**：

- 降权：不宜作为功能基因 Pathogenic 的主推依据
- 核对：VEP 注释的 `gene_symbol` 是否为邻近功能基因（注释偏移）
- 表述示例：「位于假基因相关区域，致病意义有限，需确认是否注释至功能基因」

| ClinVar | 假基因 | 建议 |
|---------|--------|------|
| Pathogenic | Yes | 核对是否针对功能基因；假基因命中提示降权 |
| VUS | Yes | 优先 incidental / 低优先级 |
| Pathogenic | No | 正常按 ClinVar + 表型解读 |

## 6. CRE（调控元件 / cCRE）

### 6.1 概念

基因表达受启动子、增强子等**顺式调控元件**控制。  
**cCRE** = candidate **C**is-**R**egulatory **E**lement，来自 ENCODE SCREEN 等数据库。

### 6.2 相关字段

| 字段 | 含义 |
|------|------|
| `vcf_info_REG_CCRE_ID` | 重叠的 cCRE ID（多个逗号分隔） |
| `vcf_info_REG_CCRE_CLASS` | cCRE 类型（见下表） |
| `vcf_info_REG_CCRE_COUNT` | 重叠 cCRE 区间数量 |
| `vcf_info_REG_CCRE_SOURCE` | 数据源版本 |

### 6.3 CRE 类型缩写

| 缩写 | 中文 | 通俗含义 |
|------|------|----------|
| **PLS** | 启动子样元件 | 可能影响转录起始 |
| **pELS** | 近端增强子样元件 | 近处调控表达 |
| **dELS** | 远端增强子样元件 | 远距离增强调控 |
| **CA-CTCF** | CTCF 相关元件 | 染色质结构/绝缘 |
| **CA-TF** / **TF** | 转录因子相关元件 | TF 结合/调控 |

### 6.4 报告展示与解读

**展示条件**：`REG_CCRE_CLASS` 非空

**合理解读**：

- **内含子 / UTR / 基因间区** + CRE 命中 → 考虑**调控致病**可能
- **错义 / 移码 / 剪接** + ClinVar Pathogenic → CRE 仅作**补充**，不作主证据
- CRE 命中不能单独推翻 ClinVar Benign 或高 gnomAD 频率

## 7. ncRNA（非编码 RNA）

### 7.1 概念

不编码蛋白质的 RNA 基因，如 **lncRNA**、**miRNA**、**snRNA** 等，可能有调控作用，解读路径与蛋白编码基因不同。

### 7.2 相关字段

| 字段 | 含义 |
|------|------|
| `vcf_info_NCRNA_GENE_ID` | GENCODE ncRNA 基因 ID |
| `vcf_info_NCRNA_GENE_NAME` | ncRNA 基因名 |
| `vcf_info_NCRNA_GENE_TYPE` | 类型（lncRNA、miRNA 等） |
| `vcf_info_NCRNA_GENE_COUNT` | 重叠 ncRNA 基因数量 |
| `vcf_info_NCRNA_SOURCE` | 数据源（如 GENCODE v49） |

### 7.3 报告展示与解读

**展示条件**：`NCRNA_GENE_NAME` 非空

说明变异落在非编码 RNA 区域，需与蛋白编码基因致病解读分开讨论。

## 8. 中国参考人群（CHN 面板）

| 字段 | 含义 |
|------|------|
| `vcf_info_CHN_ALT_CARRIER_COUNT` | 中国参考库中携带该 ALT 的个体数 |
| `vcf_info_CHN_ALT_AC` | 中国参考库中 ALT 等位基因出现次数 |
| `vcf_info_CHN_REF_SUPPORT` | 中国参考面板对该位点的支持信息 |

**与 gnomAD 的关系**：

| 字段 | 人群范围 |
|------|----------|
| `gnomAD_eas_AF` | 全球东亚人群 |
| `CHN_*` | 中国本地参考面板 |

**报告展示**：仅携带者数 &gt;0 或 ALT AC &gt;0 时展示。

**合理解读**：

- 携带者多 + gnomAD 低 → 「本地参考人群有一定携带，需谨慎评估罕见性」
- 携带者 = 0 且未展示 → **不能**写「本地极罕见」（只是面板未命中）

## 11. 解读优先级（写报告时建议顺序）

```text
1. 样本检出可信吗？
   → VAF / REF_DP / ALT_DP / DP / 解读提示

2. 功能上有害吗？
   → consequence / CADD / SpliceAI / REVEL / LOFTEE

3. 数据库与表型支持吗？
   → ClinVar / gnomAD / HPO / Open Targets 表型

4. 基因组上下文（辅助）
   → 假基因（降权）/ CRE（非编码）/ 相位（同基因多变异）/ CHN（频率）

5. 综合排序
   → pathogenic_rank / evidence_summary
```

### 11.1 禁止的不合理表述

- ❌ 「VAF 50%，故为杂合致病变异」（未看 ALT reads）
- ❌ 「命中增强子，故致病」（错义+ClinVar 已足够时 CRE 不应主导）
- ❌ 「相位 HIGH，故复合杂合」（需两个变异+家系）
- ❌ 「CHN 携带 0，故极罕见」（0 只是面板未命中）
- ❌ 「gnomAD 有频率，故良性」（需结合 ClinVar 与表型）
