## 7. 临床建议摘要（遗传咨询师视角）

### 7.1 立即建议

1. **优先验证 RRM1 截断**：通过 RRM1 IHC 和 RAD51 foci / HRD score 确认 HR 缺陷状态；若阳性，优先考虑 PARP 抑制剂 + 替莫唑胺或含铂方案。
2. **复核 TP53 / DAXX**：获取原始 filtered VCF 或 BAM 进行 IGV 复核，确认低 VAF 突变的真实性。
3. **确认 EWSR1-WT1 融合**：作为 DSRCT 诊断和潜在 WT1 靶向治疗的前提。

### 7.2 动态监测

1. **ctDNA 监测**：追踪 TP53 S241F、RRM1 截断、WT1-EWSR1 融合 VAF 变化，绘制克隆进化。
2. **IHC 验证**：RRM1、ATRX、γH2AX、SLFN11。

### 7.3 患者/家属沟通要点

- 基因组分析提示了**可成药的 HR 缺陷靶点**和**耐药机制解释**，但尚未改变诊断。

- 低 VAF 亚克隆变异的真实性尚不确定，不建议单独据此改变治疗。
