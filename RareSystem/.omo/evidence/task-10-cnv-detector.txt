## Implementation Details

### Data Structures
- CNVType enum: DEL, DUP, CNV
- CNVRegion dataclass: chromosome, start, end, copy_number, confidence_score, etc.
- ReadDepthWindow: sliding window for read depth analysis

### Key Methods
- detect_from_vcf(): Main entry point for CNV detection
- detect_deletions(): Filter for deletion events
- detect_duplications(): Filter for duplication events
- estimate_copy_number(): Copy number for specific region
- generate_cnv_report(): Summary report generation

### Detection Algorithm
1. Extract read depth from VCF FORMAT/DP field
2. Compute sliding window averages
3. Calculate global baseline depth
4. Detect depth ratio deviations (<0.75 = DEL, >1.25 = DUP)
5. Calculate confidence scores
6. Merge adjacent CNVs of same type
7. Filter by minimum length
