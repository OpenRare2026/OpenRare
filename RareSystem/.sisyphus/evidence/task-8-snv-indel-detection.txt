### Features Implemented

#### SNV Detection
- Detects single nucleotide variants (single base changes)
- Uses `variant_type` property from VCFVariant to classify SNVs
- Filters by QUAL threshold (default: 30)

#### INDEL Detection
- Detects insertions and deletions
- Distinguishes INDELs from SNVs and structural variants
- Supports variable-length REF/ALT alleles

#### Quality Filtering
- Default QUAL threshold: 30.0 (configurable)
- Filter by PASS status (configurable)
- Depth filtering (min_depth, max_depth)
- Allele frequency filtering

#### VCF Output
- `write_vcf()` method generates standard VCF format
- Includes proper header generation
- Supports custom headers from input VCF

#### Batch Processing
- `detect_batch()` processes multiple VCF files
- Returns dictionary mapping file paths to detected variants

#### Annotation Support
- Extracts rs IDs from variant ID field
- Extracts depth (DP) from INFO field
- Extracts allele frequency (AF, VAF, MAF)
- Preserves genotype information
