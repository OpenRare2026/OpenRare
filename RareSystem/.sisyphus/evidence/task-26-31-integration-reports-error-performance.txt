## Architecture Notes

1. **Dual-Track Reports**: Clinical reports use evidence chains with verified ACMG criteria, Research reports include uncertainty metrics and hypotheses

2. **Error Handling Flow**:
   - Frontend: API calls → Typed errors → Toast notifications
   - Backend: Exceptions → Middleware → Structured JSON responses
   - Both: Request IDs for traceability

3. **Caching Strategy**:
   - In-memory LRU for small, frequently accessed data
   - VCF-specific cache for parsed variants and QC metrics
   - Decorator pattern for easy function result caching
   - TTL-based expiration with automatic cleanup

4. **User Feedback**:
   - ErrorBoundary catches unexpected React errors
   - Toast system provides real-time feedback
   - All errors logged with request context
